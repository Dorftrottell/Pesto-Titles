Styles in diesem Ordner werden von Pesto Captions verwaltet.

Jede Stildatei ist eine JSON-Datei mit folgendem Format:
{
  "name":        "Mein Stil",
  "clipName":    "Nold Caption",
  "binName":     "Pesto Captions",
  "thumbnail":   "<base64-PNG>",
  "created_at":  "2026-08-19T21:00:00"
}

Thumbnails werden automatisch aus dem Resolve Media Pool extrahiert.
Dieser Ordner kann auch manuell bearbeitet oder als Git-Repository versioniert werden.
